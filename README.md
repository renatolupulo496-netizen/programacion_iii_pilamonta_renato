# Programación III

Repositorio correspondiente a la materia **Programación III**.

En este repositorio se almacenarán proyectos, ejercicios, prácticas y trabajos relacionados con el desarrollo web y de aplicaciones utilizando diferentes tecnologías del ecosistema JavaScript y TypeScript.

## Temas

### HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de una página web.

Permite definir elementos como títulos, párrafos, enlaces, imágenes, formularios, listas, tablas y otras estructuras de un documento web.

Ejemplo:

```html
<h1>Programación III</h1>
<p>Aprendiendo desarrollo web.</p>
```

### CSS

**CSS (Cascading Style Sheets)** es el lenguaje utilizado para definir la presentación y el diseño de los documentos HTML.

Permite controlar aspectos como tamaños, posiciones, márgenes, colores, tipografías, distribución de elementos y diseño adaptable.

Ejemplo:

```css
h1 {
font-size: 2rem;
}
```

### JavaScript

**JavaScript** es un lenguaje de programación utilizado principalmente para agregar comportamiento e interacción a las aplicaciones web.

Permite trabajar con variables, funciones, objetos, eventos, estructuras de control, manipulación del DOM, operaciones asíncronas y comunicación con servicios externos.

Ejemplo:

```javascript
const mensaje = "Hola, Programación III";
console.log(mensaje);
```

### TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora un sistema de tipos estático y otras características orientadas a facilitar el desarrollo de aplicaciones grandes.

El código TypeScript puede ser transformado a JavaScript para ejecutarse en los entornos compatibles con este último.

Ejemplo:

```typescript
const nombre: string = "Programación III";
console.log(nombre);
```

### NestJS

**NestJS** es un framework para construir aplicaciones del lado del servidor utilizando Node.js y TypeScript.

Está orientado principalmente al desarrollo de aplicaciones backend y utiliza una arquitectura basada en módulos, controladores y servicios.

Ejemplo conceptual:

```text
Aplicación
├── Módulos
├── Controladores
└── Servicios
```

### React

**React** es una biblioteca de JavaScript utilizada para construir interfaces de usuario mediante componentes reutilizables.

Una aplicación React puede dividir su interfaz en componentes independientes que gestionan su propia estructura y estado.

Ejemplo:

```jsx
function Saludo() {
return <h1>Hola, Programación III</h1>;
}
```
